# opencircom-foundry-boilerplate

Minimal [Foundry](https://book.getfoundry.sh/) project that compiles a Circom ZK circuit using [opencircom](https://www.npmjs.com/package/opencircom) (`^0.7.0`) and verifies a Groth16 proof on-chain.

Example circuit: prove `out = Poseidon(a, b)` and verify the proof in Solidity.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [circom](https://docs.circom.io/getting-started/installation) 2.x
- [Foundry](https://book.getfoundry.sh/getting-started/installation)

## Quick start

```bash
git clone --recurse-submodules https://github.com/jose-compu/opencircom-foundry-boilerplate.git
cd opencircom-foundry-boilerplate
npm install
npm test
```

If you already cloned without submodules:

```bash
git submodule update --init --recursive
```

`lib/forge-std` is pinned in `foundry.lock` (v1.14.0). Do **not** run bare `forge install` on a fresh checkout.

## Commands

| Command | Description |
|--------|-------------|
| `npm run compile:circuits` | Compile `circuits/hello_hash.circom` to R1CS + WASM in `build/`. |
| `npm run compile` | Compile circuits, then `forge build` (Solidity). |
| `npm run setup:zk` | Generate ptau, zkey, and `src/HelloHashVerifier.sol`. |
| `npm run generate:proof` | Build a sample proof; writes `build/proof.json` for Forge tests. |
| `npm test` | Full pipeline: circuits → ZK setup → proof → `forge test`. |
| `npm run clean` | Remove `build/`, `out/`, `cache/`. Re-run `setup:zk` after cleaning. |

The first `npm test` runs trusted-setup generation and can take about a minute. Generated artifacts under `build/` are gitignored.

If setup or tests fail, see [Troubleshooting](TROUBLESHOOTING.md) for recovery steps.

## Layout

| Path | Role |
|------|------|
| `circuits/hello_hash.circom` | Example circuit (opencircom Poseidon). |
| `scripts/compile_circuits.sh` | `circom … -l node_modules/opencircom/circuits` |
| `scripts/setup_zk.sh` | ptau, zkey, Solidity verifier export. |
| `scripts/generate_proof.js` | Witness + Groth16 proof → `build/proof.json`. |
| `src/HelloHashVerifier.sol` | Groth16 verifier (regenerated by `setup:zk`). |
| `src/PoseidonProofGateway.sol` | Example gateway calling the verifier. |
| `test/HelloHash.t.sol` | Forge tests (verifier + gateway). |
| `lib/forge-std/` | Foundry test utils (git submodule). |
